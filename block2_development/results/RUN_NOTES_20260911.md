## MIL head: the retained checkpoint is epoch 1

`mil_val` AUROC = 1.0000 at every epoch 1–31 (29 patients). Amendment 5a declared AUROC
with strict improvement, so epoch 1 was retained (train BCE 0.290; epoch 28 reached 0.0008)
and training stopped at 1 + patience 30. The run followed the declaration; the declaration
did not anticipate that the monitor would saturate at the first epoch.

Consequences, all consistent with each other:
- the reported head is lightly trained; its raw scores are under-confident, hence the
  temperature T = 0.25 (ECE 0.150 → 0.021 on dev_cal);
- every threshold (τ_abn, T) was fitted on this same head, so the external result is
  internally consistent: AUROC 0.973 [0.937, 0.998] (AML vs donors, cAItomorph);
- whether a longer-trained head transfers better or worse is unknown: more epochs on
  AML-MLL could also fit the MLL domain more tightly. Not tested (it would require
  re-fitting τ_abn and T and re-encoding cAItomorph — a post-hoc second look at the test set).

Next version: a monitor that does not saturate (validation BCE, or a harder `mil_val`),
declared before training.

## Golden set of the Jetson kit

RCH_198 (reactive → acute myeloid), ALK_199 (AML → acute myeloid), ALK_200 (**AML →
non_leukemic**), RCH_185 (reactive → non_leukemic), SCD_399 (donor → indeterminate),
MDS_157 (MDS → out_of_domain). A reproducibility set, not an accuracy set: it deliberately
keeps two model errors so the Jetson is checked on them too.

ALK_200 is the most serious error type of the grid — false reassurance on an acute
leukaemia — and deserves a case review in the paper.
