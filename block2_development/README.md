# block2_development/ — how block 2 was designed, frozen, trained and tested

Block 2 turns the leukocyte crops of a session into a session statement. It
follows the way a cytologist reads a smear — **characterise the cells, count,
decide, and refuse outside the validated domain** — and its rules were frozen in
a pre-registration before any inference on the test cohort. The deployed copy of
its code is `aster_pipeline/block2/` (repository root); its weights and
statistics are `models/mil/`.

## Outputs

```
non_leukemic                              suspicious_for_neoplasm
acute_blastic__myeloid_oriented           (+ APL_suspicion flag)
acute_blastic__lymphoid_oriented
acute_blastic__lineage_indeterminate
chronic_myeloid_pattern                   chronic_lymphoid_pattern
indeterminate | insufficient_evidence | out_of_domain
```

Nothing here is a diagnosis: lineage and entity are deferred to
immunophenotyping and molecular testing.

## The rules are frozen

`PREREGISTRATION.md` was written and hashed before any cAItomorph inference,
with γ = 0.90 and the 99th reference percentile fixed (freeze 2026-09-10).
Amendments 1–8 were adopted before the test; amendment 9 was declared, run once
after the primary test and not adopted
(`results/PREREGISTRATION.amendments.md`, `results/AMENDMENT9_OUTCOME.md`).

```bash
cd block2_development && shasum -a 256 -c results/PREREGISTRATION.sha256
```

## Reproduce

1. Obtain the public datasets (`docs/DATA.md`), set `root` in
   `datasets/sources.yaml`, then:
   ```bash
   python datasets/prepare_corpus.py --out _work/corpus
   python datasets/build_splits.py --manifest _work/corpus/manifest.csv
   ```
   The released `data_splits/block2_corpus_splits.csv` is the split used.
2. Run `notebooks/ASTER_block2_train.ipynb` on Colab (a T4 is enough, 3–5 h). The
   notebook is kept exactly as it ran. Its bootstrap cell (§0) and its first corpus
   cell (§1) pulled the repository, the block-1 weights and the corpus through a
   private authenticated transfer tool that is not part of this release. Without
   it: copy `block2_development/` to `/content/aster-block2`, the prepared corpus to
   `/content/data/corpus` (with `manifest.csv` and `splits.csv`), the prototype
   fields to `/content/data/x40_fields` (on request) and `models/yolo/wbc_detector.pt`
   to `/content/data/payload/`; in §0 remove the transfer block and its
   `data_bridge` assertion, and skip the pull cell of §1.
3. On the Jetson: `jetson/make_kit_from_repo.sh`, then `jetson/README_JETSON.md`
   and `jetson/e2e/README_E2E.md`. Results of the device campaign:
   `results/block2_v2_benchmarks/` and `docs/EVALUATION.md` § 2–3 (repository root).

Every figure of the report can be regenerated without a GPU:

```bash
python tools/make_figures.py training_run_20260911_051357Z report/figures_regenerated
```
